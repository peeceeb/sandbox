# Installation

## Stable release

To install AI_Project_Chatbot, run this command in your terminal:

```sh
uv add Chatbot_Langraph
```

Or if you prefer to use `pip`:

```sh
pip install Chatbot_Langraph
```

## From source

The source files for AI_Project_Chatbot can be downloaded from the [Github repo](https://github.com/Prasanna/Chatbot_Langraph).

You can either clone the public repository:

```sh
git clone https://github.com/Prasanna/Chatbot_Langraph
```

Or download the [tarball](https://github.com/Prasanna/Chatbot_Langraph/tarball/main):

```sh
curl -OJL https://github.com/Prasanna/Chatbot_Langraph/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd Chatbot_Langraph
uv sync
```
